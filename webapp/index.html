Color-Invariant Recognition Architecture

1. Model Choice

We leverage a ResNet-18 convolutional neural network backbone. The final fully-connected layer is removed, repurposing it as a powerful structural feature extractor.

2. Color Invariance

To ensure the model learns geometric patterns instead of relying on color, we apply extreme data augmentations during training: ColorJitter (randomizing brightness, contrast, saturation, and hue) combined with RandomGrayscale. This mathematically forces the network to become entirely "blind" to color.

3. Training Strategy

The extracted ResNet features are flattened and passed through a Linear Projection Head to compress them into a dense 128-D Embedding. This embedding undergoes L2 Normalization, allowing us to compute similarity purely using vector angles.

4. Loss Function

We optimize using the Adam Optimizer (learning rate = 1e-4). We use a proxy classification head optimized via CrossEntropyLoss to separate distinct design classes in the embedding space during training. During inference, we discard the classifier and measure Cosine Similarity directly between the L2-normalized 128-D embeddings.
